❤️ Heart AR — Interactive Anatomy

Point your camera at the printed target to view a simple 3D heart.

Ready. Press Start AR and allow camera access.

When the target image is recognized, a stylized 3D heart appears above it. Move the target or camera to view it from different angles.

Practical steps
  1. Compile assets/heart-target.svg using the MindAR Image Target Compiler.
  2. Save the downloaded file as targets.mind beside index.html.
  3. Run this folder from localhost or HTTPS, then open this page in Chrome, Edge or Safari.
  4. Press Start AR and point the camera at the printed target.

Browser permissions: camera access generally requires localhost or HTTPS. On a phone, use HTTPS. The separate 3D heart model is stored in assets/heart.glb.
